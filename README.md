# RobinKey

Next.js + TypeScript fantasy league management app.

## Scripts

```bash
npm install
npm run dev
```

App runs at [http://localhost:3005](http://localhost:3005).

- `/` — website home
- `/dashboard` — app dashboard (AVORA layout)

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 3
- Redux Toolkit
